# 003 결과의 원인을 다섯 가지로 나눈다

## 문제

"원본 액자로 걸린 작품 수"만 세면 왜 액자가 됐는지 알 수 없다. 보호자가 원해서인지, 모델이 못 해서인지, 서버가 멈춰서인지가 섞이면 모델 품질 지표와 서버 안정성 지표가 서로를 가린다.

## 선택

| 원인 | 언제 |
|---|---|
| 보호자 선택 | 올릴 때 보호자가 처음부터 액자나 입체를 고름 |
| 모델 낮춤 | 품질 미달로 한 단계 낮춤 |
| 보호자 전환 | 결과 확인 때 보호자가 더 낮은 결과로 바꿈 |
| 인프라 실패 | 장애로 재시도 중이거나 소진 |
| 결과 미도달 | 재시도 소진으로 결과를 만들지 못함 |

헷갈리기 쉬운 경우를 규칙으로 정했다.

- 재시도가 소진된 뒤 보호자가 원본 액자로 걸어도 원인은 인프라 실패와 결과 미도달로 남는다. 보호자 전환으로 세지 않는다.
- 결과를 받지 못한 작품은 "첫 결과 승인율"의 분모에서 뺀다. 결과를 보지도 못한 보호자를 거절로 세지 않기 위해서다.
