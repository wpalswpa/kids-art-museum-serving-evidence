# 002 품질 미달은 낮추고, 장애는 다시 시도한다

## 문제

워커가 "실패"를 돌려주는 이유는 둘이다.

- **품질 미달**: 모델은 돌았지만 결과가 쓸 수 없다. 예를 들어 움직이는 그림의 몸이 두 조각으로 끊긴다. 같은 입력으로 다시 돌려도 같은 결과가 나온다.
- **인프라 장애**: 엔진이 꺼졌거나, 시간이 넘었거나, 저장소·DB 오류이거나, 모델이 아직 준비되지 않았다. 다시 하면 될 수 있다.

둘을 같이 다루면 품질 미달을 헛되이 재시도하고, 장애가 "이 그림은 안 된다"로 기록된다.

## 선택

| 응답 | 처리 |
|---|---|
| `quality_below` | 재시도하지 않고 한 단계 낮춘다: 움직임 → 입체 → 원본 액자. 3D 조각도 입체 → 액자로 낮춘다 |
| `engine_down` · `timeout` · `storage` · `db` · `model_not_ready` | 같은 단계를 첫 시도 포함 최대 3번 시도한다. 소진되면 "결과 미도달"로 알리고 집계한다. 목표는 0 |

원본 액자는 모델이 필요 없으므로 낮춤의 끝에서 항상 결과가 나온다.

## 원본 프로젝트에서 본 것

팀 서버 시험(팀이 만든 그림 3장, 1회)에서 색칠한 사람 그림은 움직임을 만들지 못해 입체 그림으로 낮춰졌다. 이때 재시도 0건, 인프라 오류 0건이었다. 한 건이라 모든 실패에서 그렇다고 말할 수는 없다. 인프라 장애로 재시도가 소진되는 경로는 시험 기록이 없다.
