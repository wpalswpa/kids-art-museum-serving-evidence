# 001 원본 액자를 먼저 건다

## 문제

움직이는 그림 한 장을 만드는 데 팀 서버 측정으로 17~43초, 큰 사진은 최대 7분이 걸렸다([기록](../../evidence/README.md)). 결과를 기다리게 하면 보호자는 올린 뒤 빈 화면을 본다.

처음 설계에서는 올리기부터 전시까지 화면 5개를 거쳐 10번을 눌러야 했다. 사용자 점검에서 가장 큰 불편이었다.

## 선택

- 올리는 순간 모델 없이 만들 수 있는 **원본 액자**로 미술관에 건다.
- AI 결과는 뒤에서 작업 큐로 만든다. 다 되면 보호자가 확인하고 [좋아요]를 눌러야 바꿔 건다.
- 원본 파일은 덮어쓰지 않는다. 결과는 따로 저장한다.

## 고려한 대안

| 대안 | 버린 이유 |
|---|---|
| 결과가 나올 때까지 기다리게 하기 | 수십 초에서 몇 분을 빈 화면으로 기다린다 |
| 결과가 나오면 자동으로 바꿔 걸기 | 일그러진 움직임이 보호자 모르게 걸릴 수 있다 |

## 대가

- 첫 화면에 보이는 것은 원본 사진이라, AI의 효과는 나중에 보인다.
- 결과 확인이라는 한 단계가 늘어난다.
